## 2. 技术需求

### 2.1 后端技术栈
- Java: 17+
- Spring Boot: 3.x
- MyBatis-Plus: 3.x
- 认证授权: Sa-Token
- 数据库: MySQL 8.0

### 2.2 前端技术栈（PC 管理端）
- Vue: 3.x
- Element Plus: 最新版
- TypeScript: 5.x

## 3. 非功能性需求

- API 响应时间 < 500ms

- XSS/SQL 注入防护
